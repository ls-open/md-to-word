# 从零到一份合规的 Word

这是给人看的最短路径。完整细则在手册里（路径见 `md-to-word --contract` 里的「手册」一行）；
给 AI Agent 的逐步顺序是英文的，用 `md-to-word --guide --lang en` 取。

## 1. 装

```bash
pip install md-to-word-docx
```

## 2. 先跑通一份

```bash
md-to-word init
md-to-word hello.md -o hello.docx
```

`init` 写两份文件：`format.txt`（排版规则，整份都可以改）与 `hello.md`（能直接导出的样例）。
第一次先原样跑通，再动手改。

## 3. 写自己的稿子

正文只写内容，排版写在 `format.txt`——这是整个工具的分工，混着写就回到手工调格式了。

| 要什么 | 怎么写 |
|:--|:--|
| 标题 | `#` 一级、`##` 二级、`###` 三级；文档标题单独用 `%% 文档标题 …` |
| 摘要 / 关键词 / 表题 | 独占一行写 `%% 样式名 内容`，样式名见 `format.txt` 的词表 |
| 公式 | `$$…$$ {#eq-model1}` 独立成行；正文引用写 `@eq-model1`，**不加方括号** |
| 图 | `![说明](图.png)` 必须独立成行，题注用 `%% 图片题注 …` 另起一段 |
| 参考文献 | YAML 写 `bibliography: refs.bib` 与 `csl: chinese-gb7714-2015-numeric.csl`，正文写 `[@key]` |
| 目录 / 分节 / 分页 | `{{< toc >}}`、`{{< section 正文 >}}`（节名由格式文件声明）、`{{< pagebreak >}}` |

参考文献给 `.bib`（BibTeX / BibLaTeX）或 **CSL-JSON**（Zotero、Mendeley、Crossref 直接导出的
`.json`）都行，工具按文件内容判断，不看扩展名。声明了 `bibliography:` 之后，文献表由引擎生成，
正文不要再写一份：`%% 参考文献` 样式行会被预检拒绝，用普通段落写的列表则检测不到，会和生成的
列表并存。

## 4. 换一套格式

- **有学校的书面要求或模板**：逐条改进 `format.txt`。稿子里没用到其内容的样式行可以删；
  `文档标题 / 一级标题 / 正文 / 首段 / 普通` 永远必填，表格、图、摘要、目录、参考文献这些
  **用到了就必须保留**，缺了预检会指出。每条样式行的对齐、行距、缩进也要写全（没写的字段会让
  导出在模板生成阶段报错，并指出缺哪一项）。
- **只要一个通用的规范**：`--preset zh-academic`（中文期刊）、`zh-tw-academic`（繁體）、
  `zh-report`（技术报告）、`zh-gb9704`（党政机关公文正文版式，不含红头/版记）、
  `en-nature`（英文期刊）、`en-apa-student`（APA 7 学生论文）。
- **手上有学校给的 `.docx`**：`--base-template 学校模板.docx --keep-until "版权使用授权书"`
  按内容指定保留到哪一页，前置件原样留下，正文换成我们排的。这条路是实验性的，
  不同学校的模板差异很大，导出后务必用 Word 打开核对一遍。

## 5. 出问题了看哪

- **先单跑预检**：`md-to-word 稿件.md --validate-only`，只检查、不写 `.docx`；退出码 `0` 表示稿件与格式都能导出（模板会在临时目录试生成一次）。输出目录与写权限要到真正写文件时才知道。
- **报错带行号**，按行号改那一行。看不出怎么改时，报错里通常有一句「应写: …」。
- 预检分两级：**静默出错、事后看不出来**的（丢字、乱码、样式静默不生效）直接拦下；
  **看得见但不合规**的（多一页、题注离得远）给提醒，不拦导出。
- `md-to-word 稿件.md --json` 给机器读：`diagnostics` 里每条都带 `code`、`file`、`line`，按 `code` 分支，
  不要去解析句子。完整契约（样式名、预设路径与 sha256、退出码）用 `md-to-word --contract --json`。
- `--pdf` 只在 macOS 且本机装了 Microsoft Word 时可用；其它平台渲染请自己用 Word 打开。
- **字体与软件**：`.docx` 只记录字体名、不嵌字体，打开机器缺字体会被 Word 替换，分页可能变。
  公文的「方正小标宋简体」不是系统自带字体，需另行安装；缺字体时导出会提醒。
  WPS 能打开，但目录域不会自动展开，`STYLEREF` 章名页眉可能显示 `Error! The style is not specified.`；
  以 Microsoft Word 为准，交稿前用收件方实际使用的软件核对一次。
- 导出的 `.docx` 里 `docProps` 记着版本与格式文件的 sha256 前八位——对不上就是拿错了规则。

## 6. 三个最常见的错误

1. **样式行 `%%` 后面必须有空格**，写成 `%%文档标题` 会把整行原样印进正文。
2. **交叉引用不加方括号**：`@eq-1` 是引用，`[@eq-1]` 是引文，后者会去文献库里找一条叫
   `eq-1` 的文献，预检会拦下。
3. **公式按章编号**的 YAML 要写成两行：

   ```yaml
   crossref:
     chapters: true
   ```

   `crossref: chapters: true` 写成一行不是合法 YAML，会直接解析失败。
