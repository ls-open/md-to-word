# 从零到一份合规的 Word

这是给人看的最短路径。完整细则在手册里（路径见 `md-to-word --contract` 的最后一行）；
给 AI Agent 的逐步顺序是英文的，用 `md-to-word --guide --lang en` 取。

## 1. 装

```bash
pip install md-to-word-docx
```

## 2. 先跑通一份

```bash
md-to-word init
md-to-word hello.md -o hello.docx
```

`init` 写两份文件：`format.txt`（排版规则，整份都可以改）与 `hello.md`（能直接导出的样例）。
第一次先原样跑通，再动手改。

## 3. 写自己的稿子

正文只写内容，排版写在 `format.txt`——这是整个工具的分工，混着写就回到手工调格式了。

| 要什么 | 怎么写 |
|:--|:--|
| 标题 | `#` 一级、`##` 二级、`###` 三级；文档标题单独用 `%% 文档标题 …` |
| 摘要 / 关键词 / 表题 | 独占一行写 `%% 样式名 内容`，样式名见 `format.txt` 的词表 |
| 公式 | `$$…$$ {#eq-model1}` 独立成行；正文引用写 `@eq-model1`，**不加方括号** |
| 图 | `![说明](图.png)` 必须独立成行，题注用 `%% 图片题注 …` 另起一段 |
| 参考文献 | YAML 写 `bibliography: refs.bib` 与 `csl: chinese-gb7714-2015-numeric.csl`，正文写 `[@key]` |
| 目录 / 分节 / 分页 | `{{< toc >}}`、`{{< section >}}`、`{{< pagebreak >}}` |

参考文献只有 `.bib` 一条路：手写文献列表会被预检拒绝，先整理成 `.bib` 再引用。

## 4. 换一套格式

- **有学校的书面要求或模板**：逐条改进 `format.txt`。要求里没提到的东西不用写，写了就得写全。
- **只要一个通用的规范**：`--preset zh-academic`（中文期刊）、`zh-tw-academic`（繁體）、
  `zh-report`（技术报告）、`en-nature`（英文期刊）。
- **手上有学校给的 `.docx`**：`--base-template 学校模板.docx --keep-until "版权使用授权书"`
  按内容指定保留到哪一页，前置件原样留下，正文换成我们排的。这条路是实验性的，
  不同学校的模板差异很大，导出后务必用 Word 打开对一遍。

## 5. 出问题了看哪

- **报错带行号**，按行号改那一行。看不出怎么改时，报错里通常有一句「应写: …」。
- 预检分两级：**会让人看出来的错**直接拦下；**看不出来的**给提醒但不拦。
- `md-to-word --json` 给机器读（Agent 用这条，别去解析人看的输出）。
- `--pdf` 只在 macOS 且本机装了 Microsoft Word 时可用；其它平台渲染请自己用 Word 打开。
- 导出的 `.docx` 里 `docProps` 记着版本与格式文件的 sha256 前八位——对不上就是拿错了规则。

## 6. 最容易踩的三个

1. **样式行 `%%` 后面必须有空格**，写成 `%%文档标题` 会把整行原样印进正文。
2. **交叉引用不加方括号**：`@eq-1` 是引用，`[@eq-1]` 是引文，后者会去文献库里找一条叫
   `eq-1` 的文献，预检会拦下。
3. **公式按章编号**的 YAML 要写成两行：

   ```yaml
   crossref:
     chapters: true
   ```

   `crossref: chapters: true` 写成一行不是合法 YAML，会直接解析失败。
