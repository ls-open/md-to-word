# md-to-word 手册

期刊论文、课程报告、技术方案、学位论文，都在这一份里。学位论文多出来的部分见 §9。

English: `manual_en.md`

Markdown → 规范 Word（`.docx`）。内容与排版分离：Markdown 是源，格式全部声明在格式文件里；
导出是确定性的，同一份源任何时候重跑，产物逐字节一致。

`md-to-word --contract` 打印契约速查、入门文档与本文件的绝对路径、内置预设路径。

一次导出由**三层输入**配合完成（第三层可选）：

| 层级 | 文件 | 管什么（Agent 决策基准） |
|:--|:--|:--|
| **1. 内容与行内样式** | 稿件 `*.md` | 正文、标题分级（`#`）、结构标记（`%% 样式`、`{{< toc >}}`、`{{< section >}}`、`$$…$$ {#eq-}`）、YAML（`bibliography:`、`csl:`、`crossref:`），以及**行内局部格式**（`**加粗**`、`*斜体*`、`~~删除线~~`、`[文字]{.underline}`、`^上标^`、`~下标~`、`` `代码` ``、`[文字](url)`、`[^1]`）。 |
| **2. 样式与页面规约** | 格式 `*.txt`（不传 `-f` 时只认同目录 `format.txt`，否则用内置预设） | 页面几何（`纸张`、`页边距`、`装订线`、`对称页边距`）、校对与排版（`校对语言`、`标点压缩`）、页眉页脚与页码，以及**样式级**外观（字体、字号、段落颜色 `颜色#RRGGBB`、行距、缩进、三线表/全网格线）。 |
| **3. 前置底模** *(可选)* | `--base-template 底模.docx` | 仅在需要保留已有 `.docx` 封面、徽标、签字页等固定版式时使用（`--keep-until` / `--cover-sections` / `--keep-pages`）。底模决定前置几节与全局文档级设置，正文内容与已声明样式仍来自前两层（§9.3）。 |

判断原则：**局部微调（某几个字加粗、斜体、上下标）写在 Markdown 里；整类段落或页面参数（字体、行距、样式级颜色、装订线、双面镜像、标点压缩）写在 `format.txt` 里；复杂图形封面靠 `--base-template` 保留；只有三层加起来都做不到的项（合并单元格、行内改文字颜色、多栏、浮动环绕图）才需导出后在 Word 里补。**

## 1. 入口与退出码

| 入口 | 用法 |
|:--|:--|
| 命令行 | `md-to-word 稿件.md -o 输出.docx` |
| Python | `from md_to_word import export` |
| 从参考 `.docx` 反推要求草稿 | `md-to-word-template 参考.docx -o format.txt` |
| 入门文档 | 包内 `guide.md`：按什么顺序做、门禁怎么读、边界在哪。只装了包时先读它：`md-to-word --guide` 直接打印 |
| 从零起步 | `md-to-word init [目录]`：生成 `format.txt` 与一份能直接导出的 `hello.md` |

```bash
md-to-word 稿件.md -o 输出.docx                      # 内置中文预设 zh-academic
md-to-word 稿件.md --preset zh-tw-academic -o out.docx # 繁体中文学术预设（zh-TW，标点不压缩）
md-to-word 稿件.md --preset zh-report -o out.docx    # 中文现代技术报告预设
md-to-word 稿件.md --preset en-nature -o out.docx    # 英文期刊预设
md-to-word 稿件.md -f format.txt -o out.docx        # 显式指定格式文件
md-to-word init                                     # 生成 format.txt 与可直接导出的 hello.md
md-to-word --guide                                  # 入门文档（代办流程、门禁、边界）
md-to-word --contract                               # 契约速查 + 手册与预设路径
md-to-word --contract --lang en                     # 同上，英文版（样式名用英文正典名）
md-to-word 稿件.md -o 输出.docx --verbose            # 逐样式明细，排查「格式没生效」
md-to-word 论文.md --base-template 底模.docx --cover-sections 3 -o 论文.docx   # 见 §9.3
```

**格式要求三选一**：`-f` 显式指定；稿件同目录有 `format.txt` 就用它；否则用内置预设——未传 `--preset` 时**按稿件
语种选**：中文稿 `zh-academic`，其他语种 `en-nature`；繁体中文或技术报告可显式传 `--preset zh-tw-academic`
或 `--preset zh-report`。除 `format.txt` 之外不猜：同目录另有 `.txt` 时会在提醒里点名，要用就加 `-f`。
用了哪一份，输出里都会报出来。

**退出码**：`0` 完成；`1` 稿件、门禁或依赖问题；`2` 参数用法错误；`3` `.docx` 已写出但 `--pdf` 未渲染（非 macOS）。
`0` 表示已通过全部闸门，**不等于版面已经肉眼核对过**（§5.3）。

**`--json`**：给程序与 Agent 用。stdout 只有一行 JSON，进度与报错仍走 stderr：

```json
{"ok": true, "returncode": 0, "input": "稿件.md", "output": "…/稿件.docx", "pdf": null,
 "lang": "zh", "messages": ["…"], "errors": []}
```

键名固定、不随版本变；`messages` 与 `errors` 的值是给人读的句子，跟着稿件语种走。
`messages` 含进度、**提醒**与结尾的核对提示（提醒按类合并成一条，最多列 8 个行号），成功时
要转述的内容都在这里，不必再解析 stderr。解析方读键，不读措辞。参数用法错误（退出码 `2`）
发生在参数解析阶段，此时不产出 JSON。

**库调用**：

```python
from md_to_word import export

result = export("稿件.md", "输出.docx", preset="zh-academic")
if not result.ok:            # ok = docx 已写出（--pdf 跳过不算失败）
    raise SystemExit("\n".join(result.errors))
print(result.output_docx)    # result.messages 是进度与提醒
```

## 2. 稿件契约

稿件是普通 Markdown 加三条约定：标题用 `#`，段落样式用 `%%`，带编号公式用 `{#eq-}`。
**不存在「任意 Markdown 直接生成成品」的路径**：不符合契约时导前预检中止并指到行号，不会产出
外观正常但格式没映射上的文档。

### 2.1 标题与层级

- 文档主标题写一行 `%% 文档标题 主标题`，位置由这一行决定（可排在封面之后）；副标题、作者、
  日期同理，各写一行 `%% 副标题` / `%% 作者` / `%% 日期`。**YAML 里不写这四项**，写了会被预检拦下。
- 正文从 `#` 起是各级章节标题，层级连续不跳级。
- 某条标题（如「致谢」）要沿用 `#` 的大纲结构或按章编号，但**不进目录**，可在行尾写 `{.unlisted}` 或 `{不入目录}`（如 `# 致谢 {不入目录}`）；它仍保留同级外观，但不会触发 `{样式标题:Heading 1}` 页眉更新（需单独换页眉时可用 `{{< section >}}` 切节）。
- 标题自带阿拉伯数字编号时（`1.`、`2.1`、`2.1.1`），编号深度等于 `#` 的数量。

### 2.2 段落样式行 `%%`

需要单独指定样式的段落，在**行首**写 `%% 样式名 正文`：

```markdown
%% 摘要标题 摘要

%% 摘要 本文提出一种方法……

%% 关键词 关键词：甲；乙；丙
```

- 符号、样式名、内容同行；**一行即一段，空行结束**，没有闭合符号——与 `# 标题` 是同一条排布规则。
- 为什么标题能用符号、段落不能：标题层级只有六种，`#` 的数量就能编码；段落样式有三十多种，
  符号编码不了，所以名字写在符号后面。
- 样式名取自 §3.4 的封闭词表，写错带行号报错。**标题类（`一级标题` 等）不能写在此处**，层级只由 `#` 定。
- `参考文献` 也不能写：文献列表由 `.bib` 生成，**插在 `%% 参考文献标题` 那一行之后**（直接写
  `# 参考文献` 或 `# 参考文献 {.unlisted}` 也认），所以文献后面可以正常接附录、致谢。
- `%% 摘要标题` 与 `%% 参考文献标题` 是否进目录、是否接入 `{样式标题:Heading 1}` 动态页眉，由格式文件里的
  `加入目录` / `不入目录` 与 `加入页眉` / `不入页眉` 显式声明（无隐式升级）；写 `加入页眉` 时借用 `Heading 1`
  供 `STYLEREF` 识别，外观仍完全按该行声明写出。因 Word 原生 `TOC \o \u` 机制限制，`不入目录` 与 `加入页眉`
  不可同写。
- 所有块级元素（`$$` 公式、表格首行、独立图片行、短代码、`%%` 行）与相邻正文之间**必须隔开空行**，
  §2.5 给了哪一侧必须空的对照表；`%% 表题` 可直接贴住表格首行。

### 2.3 公式

**只有一种编号写法**：`$$…$$ {#eq-标签}`，编号由写出器按出现顺序生成。

公式里的裸 `%` 是 LaTeX 的注释起始符，**它后面整段内容会被丢掉**；字面百分号写 `\%`
（预检会拦下裸 `%`）。行内公式 `$…$` 与独立公式 `$$…$$` 的转义规则完全一致。

正文里的**变量、符号、数学式**用行内公式 `$x$` 写：反引号 `` `x` `` 落的是等宽代码字体（§2.6），
排出来不像正文。

```markdown
$$Y_{ij} = \alpha_0 + \beta_1 X_{1,ij} + \varepsilon_{ij}$$ {#eq-model1}
```

- 正文引用写 `@eq-model1`，渲染前缀按稿件语种自动取：中文稿「式」，其它「Equation」。
  **交叉引用不加方括号**：`[@eq-model1]` 是引文写法，会被当成一条文献去查，预检会拦下来并提示改成 `@eq-model1`。
  **前缀由引擎加**，正文写「见 @eq-model1」即可，写成「见式 @eq-model1」会得到「见式 式（1）」。
  要改前缀就在 YAML 里显式写 `crossref:`（§2.7），写了以 YAML 为准。
- **按章编号**（学位论文的 `（2-1）` 而非 `（1）`）：YAML 写 `crossref: chapters: true`。
  章号取公式所属一级标题的序号，不读标题里手写的数字。
- **编号外观**：格式文件写一行 `公式编号格式：（{c}-{n}）`——`{n}` 是序号（必写）、`{c}` 是章号（可选）。
  不写按语种给默认：中文稿 `（5-1）` / `（1）`，英文稿 `(5.1)` / `(1)`。公式旁的编号与正文里的
  `@eq-x` 用同一份格式渲染，不会一处带括号一处不带。
- **附录单独编号**：`# 附录A 实验数据`、`# 附录2 补充推导` 这类一级标题按**附录章**处理——
  `{c}` 取标题里那个标识（A / 2），附录内的序号重新从 1 起；标题没写标识时按出现顺序给 A、B、C。
  学校要「（附2-1）」这种前缀，就再写一行 `附录公式编号格式：（附{c}-{n}）`（不写沿用正文那套）。
  附录**不占正文章号**：附录前的六章仍是 1~6，附录后的「致谢」接着是第 7 章。
- 无编号公式直接写 `$$…$$`：不编号也不占号。写了标签但不引用是允许的，编号照出。
- 间距命令 `~` `\,` `\:` `\;` `\quad` `\qquad` 都保留（`~` 与 `\ ` 是不换行空格）；数学模式里的
  普通空格照 LaTeX 的规矩不排版。
- **多行公式**用 `cases`、`matrix`、`split` 环境（`aligned` 自动按 `split` 处理）。花括号不配对时
  转换器不报错、只会静默丢内容，预检按行拦下。
- **不要写 `\tag{…}`**：整条公式会退化成字面文本打进 Word，预检会拦下并给改写示例。

### 2.4 图、表与题注

| 元素 | 写法 | 落到的样式 |
|:--|:--|:--|
| 表格题注 | 表格上方一行 `%% 表题 **表 1** 各方案对照` | `Table Caption` |
| 表格注释 | 表格下方一行 `%% 表注 注：…` | `Table Note` |
| 图片 | `![](path/img.png){width=14cm}` | `Captioned Figure` |
| 图片（PDF 矢量图） | `![](path/fig.pdf){width=14cm}` | `Captioned Figure` |
| 图片题注 | 图片上方或下方一行 `%% 图片题注 图 1 系统架构` | `Image Caption` |

- 题注是**独立段落**，不是表格或图片的附属字段；行首 `%%` 是唯一的样式入口。「题注与图表同页」
  由题注样式上的 `与下段同页` 控制，写出器会按题注在图上方还是下方补齐。
- 图片行只描述图片本身：方括号里放无障碍替代文字，`{width=…}` 按版心钳制（超宽会被钳到版心宽，
  并出一条提醒；写百分比则直接阻断）。
- **图片可以直接引用 PDF**（matplotlib、MATLAB、Origin、Visio、TikZ 的默认导出格式）：导出时按声明
  宽度的 300 dpi 渲染第 1 页；多页只取第 1 页并出提醒，Word 不接受的格式（`.svg`、`.webp`、`.eps`）在预检拦下。
- **图片不要加 `{#fig-xxx}` 标签**：会被套上三线表的框线并失去居中。图号手写在题注文字里即可。
- 题注内部的局部排版直接写在正文里（`**表 1**` 加粗编号、`*Title*` 斜体题名），导出后忠实保留。
- 列宽默认不动（按内容排）。**要定列宽比例，就把分隔行的短横线写得长短不一**（`|:--|:--|:------|`
  约 2:2:6，按版心铺开；只数短横线）。写成一模一样 = 没指定，也因此无法强制等宽。
- 分隔行的冒号声明**该列**的对齐（`:--` 靠左、`:--:` 居中、`--:` 靠右）；**不写冒号就是「不表态」**，
  这一列按 `紧凑：` 的对齐排。冒号是显式表态，写在哪一列就覆盖哪一列的 `紧凑：`。
- 表要带首尾竖线（`| 甲 | 乙 |`），不带外框的写法认不出。

### 2.5 块级标记

只承认三种，**独占一行**且与正文隔空行：

| 标记 | 作用 |
|:--|:--|
| `{{< pagebreak >}}` | 分页 |
| `{{< toc >}}` / `{{< toc 2 >}}` | 目录域；收几级由格式文件的 `目录N级` 决定，写数字则直接指定 |
| `{{< section 页码=小写罗马 起始=1 >}}` | 收尾**它上面那一节**的分节符 |

分节的页眉页脚：**每一节默认都带**（格式文件写了 `页眉内容`，就该每页都有）。要让某一节
「不要」，在那条标记上写 `页眉=无` / `页脚=无`——封面的常见写法是
`{{< section 页码=小写罗马 起始=1 页眉=无 页脚=无 >}}`。`起始` 是谁那一节自己声明的；
**最后一节（正文）按格式文件的 `页码：` 起编**——前面是前置件那种别的编号形式、或封面那种
不显示页码的节时，正文从 `起始` 重新起；前面已经是同一套阿拉伯序号（正文后面接参考文献）时
接着往下编，不会让参考文献回到 1。

- 三者写入的是 OOXML 节点（`w:sdt` 目录域、`sectPr`），只在本工具里有效。
- `\newpage` / `\pagebreak` / `\clearpage` 在 docx 里不生效。
- 目录用**域**而不是静态列表：页码要 Word 现算。打开时自动更新一次，**要完全准确需再按一次 F9**。
- 进目录靠**大纲级别**：`#` 标题天然有（单条标题可在行尾加 `{.unlisted}` 或 `{不入目录}` 排除）；非标题类节段样式用 `加入目录` / `不入目录` 控制（不能写在正文类或 `一~六级标题` 上）。

**`{{< section … >}}` 的两条规矩**：

- **它描述的是「它上面那一节」**（OOXML 里 sectPr 归属前一节）：写在目录后、第一章前，写的却是
  前置件的小写罗马——**正文节的页码由格式文件的 `页码：` 决定**。参数词与 `页码：` 同一套。
- **后面不要再写 `{{< pagebreak >}}`**：分节符已自带「下一页」，叠加会多顶出一页（预检会提醒）。
  单节文档（报告、技术方案）通篇阿拉伯页码即可，不需要这个标记。

**哪一侧必须空行**（按标记各异，已逐例核对产物）：

| 标记 | 相邻会出事的一侧 | 后果 |
|:--|:--|:--|
| `$$…$$` 公式 | 后 | 后一行标题/正文被并进同一段 |
| `{{< pagebreak >}}`、`{{< toc >}}`、`{{< section … >}}` | 后 | 同上 |
| 独立图片行 | 前、后 | 前：并进上一段，样式跟着上一段走；后：标题被并进图片段 |
| 表格首行 | 前 | 表格退化成字面文本 |
| 标题、围栏尾行、表格末行 | 无 | 两种粘法都无害 |

### 2.6 列表、引用块、代码与行内格式

- **列表**：`- ` / `1. ` 落 `正文` 样式，编号与缩进由引擎的三级编号定义决定（在 Word 里回车、
  改级别、换编号形式都还能用）；**缩进两格就是下一级，最多三级**，第四级起并入第三级。
  引用块里放列表同样支持。
- **引用块**：`> ` 照常写；格式文件需声明 `引用块：` 样式行（内置预设已含）。
- **代码块**：``` 围栏落 `SourceCode` 样式，底模已给等宽字体、清零缩进、单倍行距、左对齐，
  **不写 `代码：` 也正常**；要改字号字色才写。行内 `` `code` `` 走 `VerbatimChar` 字符样式，
  字体在底模里定为 Consolas/宋体、**不在格式文件里**——要改就在 Word 里改这个字符样式。
- **脚注**：正文写 `[^1]` + `[^1]: 注释文字` 即可，**不必在格式文件里声明**（不写就按正文推定：
  字体对齐跟正文、字号降一档、单倍行距、序号上标）。
- **行内格式直接写在正文里**：`**加粗**`、`*斜体*`、`~~删除线~~`、`[下划线]{.underline}`、`H~2~O`、
  `x^2^`——渲染器直接写成字符属性，不需要在格式文件里声明，也不与样式级设置冲突。
- **星号要看两头**：`(1*S*,2*R*)`、`y = 4054.1*x*` 出斜体；只有开闭符**两头都紧挨字母数字**才当乘号
  （`2*3*4`、`a*b*c`）原样印出——CommonMark 会读成斜体，本工具故意不跟。字面星号写 `\*`（反斜杠转义，ASCII 标点通用），没解析的预检会提醒。
- **段落与换行**：**一行一段**，相邻的普通行不会被合并——一行一句的短段落是正常写法，各自还能
  挂 `%%` 样式。同一段落内部要换行（地址、诗句、长标题），在行尾写一个 `\` 或两个空格，写出时
  落成段内换行，段落属性仍是一套。疑似折行（上一行没有句末标点、本行紧随其后）同类合并成一条
  提醒并给出行号；本意是短段落时不必处理。
- **字体自由指定**：任意本机已安装字体（`仿宋`、`仿宋_GB2312`、`方正小标宋简体`、`微软雅黑`、`楷体`）。

### 2.7 稿件头部：YAML 只放与位置无关的配置

判据只有一条：**YAML 没有位置**。凡是「落在哪一页、哪一段」由作者决定的内容，一律写正文的样式行。
标题尤其如此——它可能在第一页第一行，也可能排在封面之后；写在 YAML 里就只能是前者。

| 元素 | 写法 |
|:--|:--|
| 文献库、CSL 样式 | YAML `bibliography:` / `csl:` |
| 交叉引用前缀、按章编号 | YAML `crossref:`（`eq-prefix`、`chapters`；`fig-prefix`、`tbl-prefix` 保留未用） |
| 引文是否加超链接 | YAML `link-citations:`，默认开启；写 `false` 时文内引用不带内链（文献表的书签仍保留） |
| 标题、副标题、作者、日期、摘要、关键词、文献区标题 | 正文样式行，见 §2.1、§2.2 |

```markdown
---
bibliography: references.bib
csl: apa.csl
---

%% 文档标题 标题

%% 作者 张三

%% 摘要 摘要正文……
```

> **YAML 里写 `title` / `subtitle` / `author` / `date` / `abstract` / `keywords` 会被预检拦下**，
> 报错直接给出该写成哪一行。这不是兼容性缺口：标题被钉死在第一页、或一段摘要静默丢掉，
> 都比报错难查得多。唯一例外是 `reference-section-title`，只提醒不拦。

### 2.8 不支持的写法

这些写法不会报错，只会把原始语法原样印进 Word，因此预检一律拦下并给出替代写法：

HTML 标签与 `<https://…>` 自动链接、横向分隔线 `---`、`====` 下划线式标题、定义列表、
待办勾选框 `- [ ]`、首尾不带竖线的表格、引用块套引用块、全角 `％％`、四空格缩进代码块、
跨行行内公式、列表项的第二段（空行 + 缩进）、列表项里的代码块（导出时明确报错，见 §6）、`#` 后面没空格的标题、
只有 `#` 没有文字的标题、图片行里 `width` 之外的属性（如 `{align=right}`）、图片宽度写成百分比
（`{width=60%}`，请写绝对长度如 `{width=14cm}`）、Word 放不下的图片格式（`.svg`、`.webp`、`.eps`，
请另存为 PNG 或直接引用 PDF）、`==高亮==`、`[文字]{.类名}`（`.underline` 除外）、
`\(…\)` 行内公式（请写 `$…$`）、`\[…\]` 块级公式（请写 `$$…$$`）、引用式链接 `[文字][ref]` 与定义行 `[ref]: url`（请写 `[文字](url)`）。

## 3. 格式文件

格式文件（下文示例统一叫 `format.txt`，文件名随意）是一门小语言：一行一种样式，行内属性写全。规矩三条：

1. **单行属性写全**：每条样式行必须写齐 `字体 字号 [加粗/不加粗 倾斜/不倾斜] 对齐 行距 段前N磅
   段后N磅 首行缩进N字符`。没有段间距或缩进时，**也要显式写** `段前0磅 段后0磅 首行缩进0字符`。
2. **按结构成套拼装**：基础五条所有文档都要（§3.4）；表格 / 图片 / 摘要关键词 / 参考文献 / 目录 /
   引用块 / 脚注按稿件实际出现的结构成套加上。用到了却漏写，导前预检会报。
3. **从预设起步**：不要在空白里写。复制内置预设（`md-to-word --contract` 给出路径）到稿件旁，
   只改用户明确提到的那几行。

**注释**：整行 `#` 是注释；**行内 `#` 不是**——`正文：宋体 小四 #加粗` 里的 `#加粗` 会被当成
没见过的词报错（唯一的行内 `#` 用法是颜色，`颜色#1F4E79`）。

### 3.1 词表（每个属性只有一种写法）

样式行格式 `<样式名>：<属性1> <属性2> …`（冒号 `：` 或 `:` 皆可）。**关键词仅认简体中文与英文（不收繁体键名**，写繁体文档时键名仍写简体或英文，例 `纸张：A4`、`校对语言：zh-TW`，正文 `.md` 本身繁体/简体/英文皆可）。**表外的词一律报错并指出行号**——解析是整词消费：认不出的词会被指出，既不静默丢弃、也不会被别的规则读错。

| 属性 | 唯一写法 | 示例 | 错误写法（会被报错） |
|:--|:--|:--|:--|
| 字体 | `<中文字体>/<西文字体>` 或单字体 | `宋体/Times New Roman` | — |
| 字号 | `<数字>pt` 或中文号数 | `12pt`、`小四`、`三号` | `12磅`、`12`（无单位）、`小四号` |
| 加粗 | `加粗` / `不加粗` | `加粗` | — |
| 倾斜 | `倾斜` / `不倾斜` | `倾斜` | `斜体`、`中等倾斜` |
| 对齐 | `居中` / `左对齐` / `右对齐` / `两端对齐` | `左对齐` | `靠左`、`靠右`、`分散对齐` |
| 颜色 | `颜色#<六位十六进制>` | `颜色#1F4E79` | `颜色深蓝`（颜色名在不同设备上解释不一，只收色值）；行内 `{color=…}` 无效 |

| 分页控制 | `与下段同页`、`段前分页`、`段中不分页`、`孤行控制` / `取消孤行控制` | `一级标题：… 与下段同页 段前分页` | — （`段前分页` 比手写 `{{< pagebreak >}}` 稳，内容增删后仍自动从新页开始） |
| 目录收录 | `加入目录` / `不入目录` | `参考文献标题：… 加入目录`、`摘要标题：… 不入目录` | 声明了目录样式时，`摘要标题` 与 `参考文献标题` **联动必填**其一；不可写在正文类（`正文`/`首段`/`普通`/`紧凑`）或 `一~六级标题`（`#` 标题单条排除见 §2.1） |

| 公式编号位置 | `公式编号：<右侧\|紧跟>` | `公式编号：紧跟` | 不写默认 `右侧`（编号靠版心右边） |
| 公式编号格式 | `公式编号格式：<模板>`，`{n}`=序号（必写）、`{c}`=章号（可选） | `公式编号格式：（{c}-{n}）` | 写 `{c}` 而稿件没开 `crossref.chapters`（预检会拦） |
| 附录公式编号格式 | 同上的模板；不写则沿用 `公式编号格式` | `附录公式编号格式：（附{c}-{n}）` | 只在稿件有附录时才有意义（附录里 `{c}` 取标题里的标识） |
| 脚注（可写可不写） | `脚注：<段落属性>` | `脚注：宋体/Times New Roman 小五 不加粗 不倾斜 左对齐 行距1.0倍 段前0磅 段后0磅 首行缩进0字符` | 写一半（`脚注：宋体 小五`）——声明了就得字段齐备 |

**页眉页脚可用的域**（封闭集合，写别的直接报错）：`{页码}`（PAGE）、`{总页数}`（NUMPAGES）、
`{样式标题:<Word 样式名>}`（STYLEREF，如 `{样式标题:Heading 1}` = 当前章标题）。域的值由 Word 计算，
打开或打印预览时更新。

### 3.2 几条容易踩的硬规矩

- **单位分工**：字号用 `pt`，行距 / 段前 / 段后 / 边框粗 / 线宽用 `磅`。写反会报错并给出应写形式。
- **缩进是每个样式行的必填字段**，判据不是「这个样式需不需要缩进」，而是「不写会不会悄悄继承」：
  正文写了 `首行缩进2字符` 之后 `Normal` 就带上了它，凡基于 `Normal` 又没自己声明的样式都会跟着缩进。
  图片段落、表内文字这类被顶右再叠加居中会**顶出右边界**。
- **`图` 与 `图片题注` 是两个样式**：`图` 是图片所在的段落（对齐由它的样式行控制），`图片题注`
  是题注文字。`图` 不写缩进会被顶右，看上去像"图片没居中"。
- **`紧凑` 只管表格里的段落**；**列表项走 `正文`**，不跟着 `紧凑` 走（否则每一项会被逐行居中）。
- **目录条目样式是生效的**：`目录一/二/三级` 写成 Word 内置样式（TOC1/2/3），更新域后字体缩进都保留。
  点线与页码由域自己画，`点线制表位` 对目录条目没有意义。
- **首行缩进与悬挂缩进互斥**（共用 `w:ind` 同一组属性），一行里都写只有一个生效，生成器直接报错。
- **线宽不写就用该边框样式的内置默认值**；1/4 磅是 Word 最细的单实线。
- **开了奇偶页不同 / 首页不同后，没显式写的那几套容器是「空白」而不是「继承默认」**：只写
  `页脚内容：{页码}` 再写 `偶数页页眉内容：…`，偶数页会整页没有页码。生成时会自动补齐空缺槽位并提示。

### 3.3 获取格式文件的五种方式

| 手上有什么 | 怎么做 |
|:--|:--|
| 空目录，先想看到成品 | `md-to-word init` 生成一份完整预设的 `format.txt` 和一份能直接导出的 `hello.md`，再照着改 |
| 参考 `.docx` 模板 | `md-to-word-template 参考.docx -o format.txt` 反推草稿，**读不出的项列在草稿末尾**，逐项核对后再用 |
| 文字或口头的格式说明 | 用户明文指定的部分照填，未提及的同套必填字段按 §3.5 推导补齐 |
| 什么都没提 | 直接用内置预设，先导一版标准 `.docx` 交付，再按反馈微调 |

### 3.4 样式名（封闭词表）

`文档标题` `副标题` `作者` `日期` `摘要` `摘要标题` `关键词` `一级标题` `二级标题` `三级标题`
`四级标题` `五级标题` `六级标题` `正文` `首段` `普通` `紧凑` `表格题注` `表注` `图` `图片题注`
`参考文献` `参考文献标题` `引用块` `页眉` `页脚` `脚注` `代码` `目录标题` `目录一级` `目录二级`
`目录三级` `目录四级` `目录五级`

- **别名**（两者等价，可任选其一）：`论文标题` = `文档标题`，`表名` / `表题` = `表格题注`，`图名` / `图题` = `图片题注`。
  除这五个之外没有同义词，表外的名字一律报错。
- 每个属性与样式名都有英文正典写法，可与中文混写（`Title:`、`Body Text:`、`bold`、`not-italic`、
  `justify`、`line-spacing 1.5`、`space-before 0pt`、`indent 0`），示例见内置预设 `en-nature.txt`。
  否定式必须带连字符：`not-bold`、`not-italic`。报错文案跟随输入语言。
- **无条件必填**：`文档标题`、`一级标题`、`正文`、`首段`、`普通`。
- **用到才必填**：二~六级标题按稿件实际层级；表格 `表格`+`表头`+`紧凑`；图片 `图`+`图片题注`；
  目录 `目录标题`+`目录一/二/三级`（四级五级可选但要连着写）；摘要 `摘要标题`+`摘要`；参考文献
  `参考文献标题`+`参考文献`（用 `.bib` 时）；引用块 `引用块`；`页眉内容` 必配 `页眉`（页脚同理）。
- **联动必填**：只有当格式文件**声明了目录样式**时，已声明的 `摘要标题` / `参考文献标题` 须显式写 `加入目录` 或 `不入目录`；
  只有当页眉写了 **`{样式标题:Heading ...}`** 时，已声明的 `摘要标题` / `参考文献标题` 须显式写 `加入页眉` 或 `不入页眉`。
  两者都未用的普通报告完全免写。

### 3.5 用户只提了一部分时怎么推

1. **明文优先**：用户或期刊写明的一律照填。
2. **学科体系兜底**：没写明时按学科借权威规范（英文社科 APA 7th、工程 IEEE、中文 GB/T 7714）。
3. **以正文为基准相对推导**：数据与注释（`紧凑`/表注/代码/脚注）比正文小一档，行距收敛到单倍，
   段前后 0 磅；题注比正文小 1 磅或同号加粗；一级标题比正文大 2~3 磅，文档标题大 4~6 磅。

具体取值不用另立一张表：内置预设就是默认值的唯一真相源。

## 4. 代办工作流（Agent）

**顺序见 `--guide`，本文件只讲事实。** 一句话的流程是：先产出一版合规 `.docx`，再按反馈微调；
没有明确格式要求就用内置预设，不要去追问格式细节。

### 参考文献：只有 `.bib` 一条路

- **无参考文献**：YAML 不写 `bibliography:` 与 `csl:`，正文不出现 `[@key]`。
- **有参考文献**：YAML 写 `bibliography: refs.bib` 与 `csl: <样式>.csl`。文献列表由引擎生成，
  用户**不写**列表、不写 `%% 参考文献`（会被预检拒绝），只在文献区标题那一行之后由引擎插入。
- **手写文献列表不受支持**：只有手写条目时，先据此生成 `references.bib` 再引用。
- `csl:` 写内置文件名（如 `apa.csl`）时自动在包内查找；也可写相对稿件目录的路径或绝对路径。
  **自带 CSL 会自动规范化**：去掉 `<bibliography>` 上的 `hanging-indent` 与 `line-spacing` 并提示一行——
  直接格式优先级高于样式，不剥掉的话换个 CSL 悬挂缩进和行距就变了。
- **数字制的序号成一栏**：引擎在 `[1]` 后补一个制表符，`参考文献` 写了 `悬挂缩进` 时制表位正落在缩进处。
- **不写 `csl:` 时的默认**：中文稿按 GB/T 7714-2015 数字制，其他按 APA 7th（判据是正文语种）。
  默认样式只有一处定义，不会因为换入口换出两种文献表。
- **正文引用写法**：

  | 写法 | 渲染 |
  |:--|:--|
  | `[@key]` | 括号引用；多篇 `[@a; @b]`，带页码 `[@a, p. 33]`（`[@a, 33]` 同义），带前缀 `[see @a]` |
  | `@key` | 叙述引用（`正如 @a 所指出`）；带页码 `@a [p. 33]` |
  | `[-@a]` | **不支持**：引文引擎不实现「只出年份」，预检会拦下并给出改法 |
  | `user@example.com` | 原样输出——`@` 前是 ASCII 字母或数字时不算引用（汉字不算，中文里写「见@eq-1」是引用） |

- **对不上的 key 会被导前预检拦下**：正文引了 `.bib` 里没有的 key，或 YAML 漏写 `bibliography:`，
  都在导出前报错并指到行号。

## 5. 导出与门禁

### 5.1 一条命令做完六件事

```
导前预检 → 生成样式模板 → 读成文档模型 → 写出 OOXML → 防丢内容检查 → 产物与格式要求逐条对账
```

样式模板每次导出实时生成，不落盘复用；**样式**只有一个来源，就是格式文件。

防丢内容检查比两样：原稿里的三位以上小数，和每一个汉字。少了就报错并指出缺的是哪个，`--no-postflight` 可跳过。

- **默认预设与繁体中文兼容**：不传 `-f` / `--preset` 时中文走 `zh-academic`；若稿件为**繁体中文（Taiwan/HK/Macau）**，建议传 `--preset zh-tw-academic`（或复制其修改），正文默认 `PMingLiU`（新细明体）+ 标题 `Microsoft JhengHei`（微软正黑体）+ `校对语言：zh-TW` + `标点压缩：不压缩`，以保持繁中标点与字形在各平台 Word 中正确显示。

拿到机构、高校或期刊下发的 `.docx` 时有两条路：

- **只要它的样式**：把格式读成格式文件，再照常导出（下面这段）。
- **要连它的封面一起保留**：那份 `.docx` 当底模，`--base-template` 把正文灌进去。
  样式仍然来自格式文件，底模只贡献前置件与全局文档设置。做法见 §9.3。

```
md-to-word-template 参考模板.docx -o format.txt   # 反推草稿，逐条核对
md-to-word 论文.md -f format.txt -o 论文.docx
```

反推只读格式数据：纸张、页边距、装订线、对称页边距、标点压缩、页眉页脚距边界、页码格式、文档网格、
校对语言、页眉页脚文字与域、表格（按文档里表格**实际引用**的样式读，不必叫 Table）、各样式的字体
字号行距段距缩进对齐。导出仍由本工具生成模板；多节模板（封面、目录、正文）同样适用，节的分界在
正文里用 `{{< section >}}` 标记。

属性按**生效值**读：样式自己没写的，沿 `basedOn` 链和 `docDefaults` 找，所以「派生样式的属性
写在基础样式上」这种最常见的写法读得出来，不会落成空值或默认值。

**反推的边界**——分两种，都会写进草稿末尾的清单，不猜值填空：

- **读不出来**：参考文件靠**段落直接格式**表达的东西（手敲的行距、手动的缩进、句子里单独加粗），
  以及没挂样式的表格。本工具读的是样式表，这一层读不到。
- **读得出来、但格式文件表达不了**：下边框以外的边框（上/左/右边框、方框）、底纹（段落底色、
  表头灰底、灰底字）、页眉页脚里的图片与图形（学校 logo、横线）。这些会按文档汇总成一条，
  列出是哪几个样式用的，导出后要在 Word 里补。

页眉页脚按**引用**取（各节写法不同时取正文节并提示），不会把三个章名当成三种页眉。
所以反推出来的是**草稿**：草稿末尾列出需人工确认的项，逐条核对后再用，别直接拿去排版。

### 5.2 预检分两级，判据是「错了看不看得见」

| 级别 | 判据 | 例子 |
|:--|:--|:--|
| **阻断** | 静默出错，事后看不出来 | 内容丢字（表格列数不符）、退化成字面文本（`\tag{}`、未定义交叉引用）、格式不生效（样式名不在模板里、格式文件漏写表格样式）、YAML 里写了摘要关键词、题注写进图片方括号 |
| **提醒** | 看得见，只是不合规 | 图片宽度超版心（会被钳）、题注离图表远了、标题跳级、分节后多写分页、折行段落、词内星号按字面印出 |

提醒不阻断导出：作者可能有意为之，也可能打算在 Word 里收尾。若设为阻断，使用者只能以 `--no-check`
绕过，连真正的阻断项也会一并关闭。另有 `--no-postflight`（防丢数）与 `--no-audit`（逐条对账）两个同类
开关，三个都只为排查工具本身，交付时不要用。

同一类提醒**合并成一条**输出，最多列 8 个行号、其余报数量，不按处刷屏；提醒同时进 `--json` 的 `messages`，
技能与脚本据此转述。

### 5.3 交付前必须肉眼核对

命令返回 `0` 只说明结构、样式与数量都过了闸门，**版面仍须在 Word 中人工核验**：表格行高列宽按内容
自适应、公式与题注的落版、页眉页脚只有真打开才能确认。导出末尾会输出这一条提醒。

**含动态域（目录、`{样式标题}` 页眉、跨节页码）或复杂宽表时，正式交付前开一次 `--pdf`**——这是唯一
能把域真正展开、看到真实分页的方式：

```bash
md-to-word 稿件.md -o 输出.docx --pdf
```

拿到 PDF 后抽四处核对：首页 / 最宽表格页 / 公式密集页 / 参考文献页。不可用时（Windows、未装 Word、
或装了但从没启动过）自动跳过，不影响 `.docx` 产出（退出码 `3`）。

### 5.4 学位论文

封面、前置件、分节页码、按章编号、双线章名页眉这些只跟学位论文有关的部分，集中在 §9。
`--base-template` 那条路也在那里（§9.3）。

## 6. 能力边界

**支持**：样式行能声明的全部段落属性（字体、字号、加粗倾斜、样式级颜色、对齐、缩进、行距、段距、边框与
表格线宽、字符间距、分页控制）；纸张、装订线与对称页边距；校对语言与标点压缩；页眉页脚与三类域；
奇偶页/首页不同、分节页码；表格（三线表、全网格线、顶底线、无边框、跨页重复表头、单元格对齐与
内边距、列宽比例）；原生 OMML 公式与交叉引用；图与题注；`.bib` + CSL 文献；行内格式（加粗、斜体、
删除线、下划线、上下标、行内代码、链接）；三级列表与引用块内列表；脚注；以及通过 `--base-template`
保留已有 `.docx` 的封面/前置件（§9.3）。

**各层分工与硬边界**（需三层组合，或导出后在 Word 里补）：

| 需求 | 能不能做到 / 哪层负责 |
|:--|:--|
| 定制图形封面、徽标、签署页、下划线填空表 | 不能仅靠 `format.txt` 从零画出来；**有现成 `.docx` 模板时用 `--base-template 底模.docx --keep-until …` 直接保留前置页并灌入正文**（§9.3）；没有 `.docx` 底模时，简版文字封面可用 `%%` + `{{< section >}}`，复杂图形封面需导出后在 Word 合并 |
| 整段/整类样式改字体、颜色、间距、对齐 | **MD + `format.txt` 协同**：`format.txt` 写样式属性（如 `颜色#1F4E79`），MD 用 `#` 或 `%% 样式名` 命中 |
| 某几个字局部加粗、斜体、上下标、下划线、等宽 | **MD 层直接完成**：正文写 `**加粗**`、`*斜体*`、`H~2~O`、`x^2^`、`[字]{.underline}`、`` `code` ``，不用改 `format.txt` |
| **行内**给某几个字单独改文字颜色（如局部标红） | **不支持**（无 `{color=…}` 行内语法；颜色只作用于样式级 `颜色#RRGGBB`），需导后在 Word 改或抽成独立段落样式 |
| 合并单元格、斜线表头、单元格底纹 | **不支持**（Markdown 表格只有规则二维网格）；按网格导出后到 Word 里合并 |
| 多栏混排、文字环绕的浮动图 | **不支持**（单栏是唯一正文版式，图片走独立居中图段）；双面印刷的 `对称页边距：开` 与 `装订线` 支持 |
| 图以矢量形式嵌入（PDF 原样进 Word） | Word 内联图片只认位图，PDF 图按 300 dpi 栅格化后嵌入；印刷分辨率够，但不再是无限放大矢量 |
| 带编号公式里求和/积分的上下限上下排 | Word 只有显示式才上下排；带编号公式为行内公式 + 右侧制表位，内容与符号完整，排法不同 |
| 任意制表位 | 只有 `点线制表位` 一种（右对齐 + 点线引导） |
| 某节标题**不入目录但又切换章名页眉** | Word 原生 `TOC \o \u` 域会把 `Heading 1` 收进目录，故 `不入目录` 与 `加入页眉` 互斥；需此类效果可用 `{{< section >}}` 切节设置该节页眉 |
| 脚注位置 | 固定印在引用它的那一页底部，Word 的版面规则 |
| 列表超过三级 | 第四级起并入第三级 |

**CSL 引文的排版差异**（引文引擎的取舍：内容不缺，只是排法与参考实现有出入，见到再对照）：

| 会看到什么 | 怎么办 |
|:--|:--|
| 题名带引号的样式（MLA、Chicago 一类）把句点印在引号外：`“A Study of Things”.`；题名以问号结尾时还多一个句点：`“Why Things Happen?”.`。引号内标点按引文引擎自己的实现，个别样式在引号与逗号相邻处会多一个标点 | 导出后在 Word 里搜 `”.` 逐条改，或换用不引题名的样式（APA、Nature、GB/T 7714） |
| 同一作者同年的多条文献，样式声明 `collapse="year-suffix"`（如 `springer-basic-author-date.csl`）时年份重复：`(Smith 2020a, 2020b, 2020c)`，参考实现作 `(Smith 2020a, b, c)` | 内容不缺，只是不紧凑；要严格照样式排时在 Word 里合并年份 |
| 年份区间只印起始年：`year = {2020-2021}` 输出 `2020`，结束年份不出现 | 按起始年导出，区间在 Word 里补，或拆成两条文献 |
| 只印 `et al.`、不列作者的样式（`et-al-use-first="0"`）多一个前导空格：`( et al., 2020)` | 换用列作者的样式，或导出后删掉那个空格 |
| 样式里「只在需要消歧时」才走的分支（`<choose>` 的 `disambiguate="true"`）会无条件走：本该走普通分支的引用也带出那一支的内容 | 少数样式如此；导出后核对该条引用，必要时在 Word 里改回 |
| 姓名的全名级消歧（`all-names`）只按第一作者判重：重名出在第二作者时不被区分，`(Roe, Doe, 2020)` 两条一模一样 | 用页码区分，或在正文里写全作者 |
| 叙述式引用只在「单条文献、样式输出的是一整对圆括号」时改写成 `Smith (2020)`；多篇并列、带前缀或数字制仍是括号式 / 编号 | 多篇分成两句写；单条 `@key` 不受影响 |

**做不到**：列表项里放围栏代码块。列表项只承载段落，代码块会被写成顶层段落、与列表项的从属关系消失；宁可报错也不静默挪位，所以导出会中止并提示把代码块移出列表。

**静默钳制**：图片宽度超过版心会被钳成版心宽（A4 + 2.54cm 边距下 15.92cm，有装订线再减它）。
预检会按格式文件算出真实版心，超宽时出一条提醒（不阻断导出）；百分比宽度则直接阻断。

## 8. 报错速查

**文案跟随稿件语种**：中文稿读中文报错，英文稿读英文报错（含方括号里的类别标签与样式名举例）。
方括号标签是稳定的类别标识，便于对照下表；括号里的具体说明给出该改哪一行。

| 现象 | 原因与处置 |
|:--|:--|
| `[结构样式缺失]` | 稿件用到了某结构，格式文件没声明对应样式行。按报错给的行号补那一行，或换用预设 |
| `[段落样式]` | `%%` 后面的名字不在 §3.4 词表里，核对写法 |
| 格式文件解析失败 | 属性词不在 §3.1 词表里；报错会给行号、原词与应写形式 |
| 图片没居中 | `图：` 样式行没写缩进，继承了正文的首行缩进 |
| 中文全篇标红波浪线 | 格式文件没写 `校对语言：zh-CN`（或繁体中文 `校对语言：zh-TW`） |
| 公式报「丢了字符」或「结构不完整」 | 花括号不配对（`\frac{a}{b`）最常见；按报错行号补全。字符与间距的增减都会被拦下，不会静默出稿 |
| 参考文献没生成 | YAML 缺 `bibliography:`、正文没有 `[@key]`、或没写文献区标题行 |
| 目录条目字体不对 | 目录条目样式没写成 Word 内置样式（`目录一/二/三级`），或写了 `点线制表位`（无效） |
| 页眉显示「错误!未找到引用源」 | `{样式标题:X}` 里的 X 不是 Word 样式名（应写 `Heading 1`） |
| 字体看起来对、Word 里却不是 | 参考模板的主题属性覆盖了显式字体；反推后由生成器剥离 `asciiTheme`/`eastAsiaTheme`/`themeColor`/`themeFill` 等 |
| 同一份稿子两次导出不一致 | 不应发生：产物逐字节可复现；出现即报缺陷 |

### 9.2 封面与前置件

封面不是一页，通常是一组：中文封面、英文封面、原创性声明、版权授权书，中间还夹空白页。
它们**都是版式**，`format.txt` 表达不了——md 能给居中、字号、段前段后、图片，给不了绝对定位、
文本框、固定行高下的精确对齐。

三条路，按能保证的程度排：

1. **灌进已有模板（`--base-template`，推荐）**：把高校、期刊或机构下发的那份 `.docx` 当前置件，正文换成我们排的。见 §9.3。
2. **纯文字封面**：若封面只有文字与简单图片、没有校徽定位框线，可直接用 Markdown 排（`%%` 样式行 + 图片 + 一个 `{{< section 页眉=无 页脚=无 >}}` 收尾），提前确认对方规范是否允许。
3. **导出后在 Word 里合并**：工具只产正文，封面另做再合并。最稳，但要手工。
   **不要用复制粘贴把已有封面粘进产物**——撞名的样式会被 Word 重定义，整篇正文跟着变形。

### 9.3 把正文灌进已有封面模板（`--base-template`）

```bash
md-to-word 稿件.md -f format.txt --base-template 底模.docx --keep-until 版权使用授权书 -o 输出.docx
```

`--keep-until 某段文字`：保留到出现这段文字的那一节为止，工具报出节数；找不着时它列出每节开头。
`--cover-sections N` 直接说节数。`--keep-pages P` 按页说，要装 Word（得真排一次版）。

**目录不保留**：底模里有目录（域或手工排的都算）时，切点必须停在它之前——目录由稿件写
`{{< toc >}}` 生成。切深了直接拒绝，并报出上限。

底模贡献：前置件那几节（连它自己的页面设置、页眉页脚、页码格式）、文档级设置（主题、兼容模式、
标点压缩、双面镜像）、以及我们没声明的样式。正文的纸张、页边距、装订线、页码格式和声明过的样式来自格式文件。

文档级设置只有一份：单独导出时 `对称页边距` 与 `标点压缩` 由格式文件控制；**使用 `--base-template` 时则整篇跟着底模的 `settings.xml` 走**（标点压缩、兼容模式、双面装订镜像、默认字体字号）。所以灌入底模后，正文的换行位置、以及底模开了镜像时对开页的左右边距，可能和单独导出有出入，而字体、字号、行距、缩进与正文页边距数值仍以格式文件为准。

**验不过就不产出文件**。结构验真跨平台跑：前置件逐节点一致、原件的样式编号主题一样没少、
正文引用的样式都存在。版面验真在装了 Word 的机器上做：原件和产物各排一次版，逐页逐词比坐标，
差一点就删掉产物。Windows 上只跑第一层，导出会说清楚。

它验不了两件事：切点选得对不对（导出时会报「切点之后第一段是「…」」），以及封面里的域、宏按钮
打开时要不要点一下。

### 9.4 分节与页码

**一条规矩**：`{{< section … >}}` 描述的是**它上面那一节**，不是后面那一节。所以「前置件小写罗马」
写在目录后、第一章前。

- 封面那一节的写法：`{{< section 页码=小写罗马 起始=1 页眉=无 页脚=无 >}}`——三个参数一起给，
  否则封面会带上页眉页码。
- **正文的页码由格式文件的 `页码：` 决定**：前面是前置件（罗马字）或封面（不显示页码）时，正文
  按 `起始` 重新起编；前面已经是同一套阿拉伯序号（正文后面接参考文献）时接着编，不会回到 1。
- 分节符自带「下一页」，**后面不要再写 `{{< pagebreak >}}`**，叠加会多顶出一页（预检会提醒）。

### 9.5 公式按章、按附录编号

- 按章：YAML 写 `crossref: chapters: true`，章号取公式所属一级标题的序号，不读标题里手写的数字。
- 附录：`# 附录A 实验数据` 这类一级标题按附录章处理，`{c}` 取 A，附录内的序号从 1 起；
  标题没写标识时按出现顺序给 A、B、C。附录**不占正文章号**——附录前的六章仍是 1~6，后面的「致谢」
  接着是第 7 章。
- 学校要「（附2-1）」这种前缀，写一行 `附录公式编号格式：（附{c}-{n}）`；不写就沿用正文那套。

### 9.6 双线章名页眉

格式文件写 `页眉内容：{样式标题:Heading 1}`，页眉就跟着每章的标题走。两件事必须同时成立：

- 稿件里每章都用 `#`（一级标题），写 `##` 就取不到；
- `参考文献标题`（或 `摘要标题`）须显式声明 `加入目录 加入页眉`（若不想入页眉则写 `不入页眉`），否则参考文献那几页的页眉还停在前一章；未接入 `Heading 1` 的 `{.unlisted}` 标题同样不会切换页眉（需要时用 `{{< section >}}`）。

### 9.7 常见坑

这些都是真实反馈里修出来的，撞上了不报错、只是悄悄不对：

| 现象 | 原因 |
|:--|:--|
| 表格设了居中却靠左 | 分隔行写了冒号才是「每列表态」，整表对齐由 `紧凑：` 那行的对齐决定 |
| 公式把上下两行文字挤住 | 固定行距（`行距20磅`）比公式矮；改用 `行距最小值` 或加大行距 |
| 声明「每页 22 行」却没生效 | 行数有上限：版心高 ÷ 正文行高。超过的声明不会生效，预检会提醒 |
| 目录里没有参考文献 | 参考文献标题未写 `加入目录`（或写了 `{.unlisted}` / `{不入目录}`） |
| 页码接着前置件往下编 | 见 §9.4：正文按格式文件的 `起始` 重新起 |
| 附录公式编成 (1-1) | 附录标题没写标识，或没写 `附录公式编号格式` |
| 前置件缺页眉但又要有页码 | `页眉=无` 只关页眉；页码走 `页脚`，别写成 `页脚=无` |
