## 2. 封面与前置件

封面不是一页，通常是一组：中文封面、英文封面、原创性声明、版权授权书，中间还夹空白页。
它们**都是版式**，`format.txt` 表达不了——md 能给居中、字号、段前段后、图片，给不了绝对定位、
文本框、固定行高下的精确对齐。

三条路，按能保证的程度排：

1. **灌进学校模板（推荐）**：把学校给的那份 `.docx` 当前置件，正文换成我们排的。见下一节。
2. **纯文字封面**：学校封面只有文字、没有校徽和固定框线时，可以直接用 md 排（`%%` 样式行 + 图片 +
   一个 `{{< section 页眉=无 页脚=无 >}}` 收尾）。这类封面属于特例，先确认学校允不允许这么干。
3. **自己在 Word 里排**：工具只产正文，封面另做再合并。最稳，但要手工。
   **不要用复制粘贴把学校封面粘进产物**——撞名的样式会被 Word 重定义，整篇正文跟着变形。

### 2.1 把正文灌进学校模板

学校模板里的封面、原创性声明、双线章名页眉，用 `format.txt` 表达不了；手工复制粘贴又会被
Word 重定义同名样式，把整篇正文带歪。这条路换一种做法：**以学校模板为底模**，前端保留它的
前几节，后面换成我们排的正文。

```bash
md-to-word 稿件.md -f format.txt --base-template 学校模板.docx --keep-until 版权使用授权书 -o 输出.docx
```

**推荐按内容说**：`--keep-until 某段文字` ——「保留到出现这段文字的那一节为止」。人本来
就是这么想的（「留到版权使用授权书那页」），也就不用去数节。工具在底模的正文里找这段文字，
落在第几节就保留几节，并把数字报出来：「保留到「版权使用授权书」所在的第 3 节」。找不着时
它会把底模每节的开头列出来，让你照着挑。这一步只看 XML，**不需要装 Word**。

也接受两种机器的说法：

- `--cover-sections N`：底模前 N 节属于前置件，原样保留。
- `--keep-pages P`：按页说，工具试切几次换算成节数，报出「前 6 页 = 前 3 节」。**要装 Word**
  （换算得真排一次版）。

页和节不是一回事：你那套模板 3 节 = 6 页，中间夹着空白页。所以按页数说很容易差一页，
按内容说不会。这个数不猜——切浅了会丢掉
后面的封面，切深了会把摘要也留下，两种都不报错，所以导出时会明说「切点之后的第一段是「…」」，
请对照看一眼。

**底模到底贡献了什么**（别以为它只贡献封面）：

| 来自底模 | 来自格式文件 |
|:--|:--|
| 前置件那几节：原样，连它自己的页面设置、页眉页脚、页码格式 | 正文的纸张、页边距、页码格式 |
| 文档级设置：主题、兼容模式、奇偶页不同 | 格式文件里声明的那二十多条样式 |
| **我们没声明的样式**：底模里原样留着 | 页眉页脚的内容与样式 |

所以「灌完之后和用我们自己的底模一样」只在**声明过的样式**和正文版式上成立。底模里那些
我们没写的样式（脚注、题注、学校自定义的），仍然是学校的样子——这通常正是你要的，
但它意味着**换个底模，正文的边角可能跟着变**。

规矩只有一条：**验不过就不产出文件**。验真分两层：

- **结构验真（任何平台都跑）**：前置件的每个节点都要和原件逐字节一致，原件的样式、编号定义、
  主题一样不能少，样式不重名、每种类型只有一个默认，脚注引用都能解析。这一层保证的是「我们
  没动封面」。
- **版面验真（有 Word 的机器才做得了）**：把原件和产物都交给 Word 排一次版，逐词比前置件页面的
  坐标，差一点就删掉产物报错。这一层保证的是「排出来也一样」——分页、空白页这些从 XML 里看不出来。

**目录不保留**：底模里若有目录（Word 插的域、手工一条条排的都算），切点必须停在它之前。
目录要由你的稿件生成——写一行 `{{< toc >}}`，页码才是对的；模板那份是作者照着他自己的正文
排的，留着只会印出和他内容对不上的条目，而且它是域，Word 排版时按我们的新标题重算，两份
永远不一样，逐页验真也就比不平。切深了直接拒绝，并告诉你最多能保留前几节。

Windows 上只跑第一层，导出会明确告诉你「只做了结构验真，版面请自己开 Word 对照看一遍」。
（PDF 渲染目前只有 macOS 实现，Windows 支持一直没做。）

它验不了的两件事：切点选得对不对（靠上面那句提示），以及封面里的域、宏按钮打开时要不要点一下。

**页眉页脚分两种**：正文那几节的是我们生成的，样式撞名被改名时，里面的 `STYLEREF` 域会跟着
改成新名字；底模自己那几节的原样保留，我们一个字都不动。所以底模的页眉里若写着指向不存在
样式的 `STYLEREF`，Word 会印出「错误!使用"开始"选项卡将 … 应用于要在此处显示的文字」——
那是模板本身的问题（原件打开时就这样），不是灌进去才有的。开 Word 打开原件确认一下即可。

## 3. 分节与页码

**一条规矩**：`{{< section … >}}` 描述的是**它上面那一节**，不是后面那一节。所以「前置件小写罗马」
写在目录后、第一章前。

- 封面那一节的写法：`{{< section 页码=小写罗马 起始=1 页眉=无 页脚=无 >}}`——三个参数一起给，
  否则封面会带上页眉页码。
- **正文的页码由格式文件的 `页码：` 决定**：前面是前置件（罗马字）或封面（不显示页码）时，正文
  按 `起始` 重新起编；前面已经是同一套阿拉伯序号（正文后面接参考文献）时接着编，不会回到 1。
- 分节符自带「下一页」，**后面不要再写 `{{< pagebreak >}}`**，叠加会多顶出一页（预检会提醒）。

## 4. 公式按章、按附录编号

- 按章：YAML 写 `crossref: chapters: true`，章号取公式所属一级标题的序号，不读标题里手写的数字。
- 附录：`# 附录A 实验数据` 这类一级标题按附录章处理，`{c}` 取 A，附录内的序号从 1 起；
  标题没写标识时按出现顺序给 A、B、C。附录**不占正文章号**——附录前的六章仍是 1~6，后面的「致谢」
  接着是第 7 章。
- 学校要「（附2-1）」这种前缀，写一行 `附录公式编号格式：（附{c}-{n}）`；不写就沿用正文那套。

## 5. 双线章名页眉

格式文件写 `页眉内容：{样式标题:Heading 1}`，页眉就跟着每章的标题走。两件事必须同时成立：

- 稿件里每章都用 `#`（一级标题），写 `##` 就取不到；
- `参考文献` 那个标题在结构上也得是一级标题，否则参考文献那几页的页眉还停在前一章。

## 6. 常见坑

这些都是真实反馈里修出来的，撞上了不报错、只是悄悄不对：

| 现象 | 原因 |
|:--|:--|
| 表格设了居中却靠左 | 分隔行写了冒号才是「每列表态」，整表对齐由 `紧凑：` 那行的对齐决定 |
| 公式把上下两行文字挤住 | 固定行距（`行距20磅`）比公式矮；改用 `行距最小值` 或加大行距 |
| 声明「每页 22 行」却没生效 | 行数有上限：版心高 ÷ 正文行高。超过的声明不会生效，预检会提醒 |
| 目录里没有参考文献 | 参考文献标题没进目录层级 |
| 页码接着前置件往下编 | 见 §3：正文按格式文件的 `起始` 重新起 |
| 附录公式编成 (1-1) | 附录标题没写标识，或没写 `附录公式编号格式` |
| 前置件缺页眉但又要有页码 | `页眉=无` 只关页眉；页码走 `页脚`，别写成 `页脚=无` |
