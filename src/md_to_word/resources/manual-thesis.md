## 2. 封面与前置件

封面不是一页，通常是一组：中文封面、英文封面、原创性声明、版权授权书，中间还夹空白页。
它们**都是版式**，`format.txt` 表达不了——md 能给居中、字号、段前段后、图片，给不了绝对定位、
文本框、固定行高下的精确对齐。

三条路，按能保证的程度排：

1. **灌进学校模板（推荐）**：把学校给的那份 `.docx` 当前置件，正文换成我们排的。见下一节。
2. **纯文字封面**：学校封面只有文字、没有校徽和固定框线时，可以直接用 md 排（`%%` 样式行 + 图片 +
   一个 `{{< section 页眉=无 页脚=无 >}}` 收尾）。这类封面属于特例，先确认学校允不允许这么干。
3. **自己在 Word 里排**：工具只产正文，封面另做再合并。最稳，但要手工。
   **不要用复制粘贴把学校封面粘进产物**——撞名的样式会被 Word 重定义，整篇正文跟着变形。

### 2.1 把正文灌进学校模板

```bash
md-to-word 稿件.md -f format.txt --base-template 学校模板.docx --keep-until 版权使用授权书 -o 输出.docx
```

`--keep-until 某段文字`：保留到出现这段文字的那一节为止，工具报出节数；找不着时它列出每节开头。
`--cover-sections N` 直接说节数。`--keep-pages P` 按页说，要装 Word（得真排一次版）。

**目录不保留**：底模里有目录（域或手工排的都算）时，切点必须停在它之前——目录由稿件写
`{{< toc >}}` 生成。切深了直接拒绝，并报出上限。

底模贡献：前置件那几节（连它自己的页面设置、页眉页脚、页码格式）、文档级设置（主题、兼容模式、
标点压缩）、以及我们没声明的样式。正文的纸张、页边距、页码格式和声明过的样式来自格式文件。

文档级设置是整份文件共用的，只能有一份。所以正文的**换行位置**可能和单独导出略有出入；字体、
字号、行距、缩进、页边距都是我们的，格式要求不受影响。

**验不过就不产出文件**。结构验真跨平台跑：前置件逐节点一致、原件的样式编号主题一样没少、
正文引用的样式都存在。版面验真在装了 Word 的机器上做：原件和产物各排一次版，逐页逐词比坐标，
差一点就删掉产物。Windows 上只跑第一层，导出会说清楚。

它验不了两件事：切点选得对不对（导出时会报「切点之后第一段是「…」」），以及封面里的域、宏按钮
打开时要不要点一下。

## 3. 分节与页码

**一条规矩**：`{{< section … >}}` 描述的是**它上面那一节**，不是后面那一节。所以「前置件小写罗马」
写在目录后、第一章前。

- 封面那一节的写法：`{{< section 页码=小写罗马 起始=1 页眉=无 页脚=无 >}}`——三个参数一起给，
  否则封面会带上页眉页码。
- **正文的页码由格式文件的 `页码：` 决定**：前面是前置件（罗马字）或封面（不显示页码）时，正文
  按 `起始` 重新起编；前面已经是同一套阿拉伯序号（正文后面接参考文献）时接着编，不会回到 1。
- 分节符自带「下一页」，**后面不要再写 `{{< pagebreak >}}`**，叠加会多顶出一页（预检会提醒）。

## 4. 公式按章、按附录编号

- 按章：YAML 写 `crossref: chapters: true`，章号取公式所属一级标题的序号，不读标题里手写的数字。
- 附录：`# 附录A 实验数据` 这类一级标题按附录章处理，`{c}` 取 A，附录内的序号从 1 起；
  标题没写标识时按出现顺序给 A、B、C。附录**不占正文章号**——附录前的六章仍是 1~6，后面的「致谢」
  接着是第 7 章。
- 学校要「（附2-1）」这种前缀，写一行 `附录公式编号格式：（附{c}-{n}）`；不写就沿用正文那套。

## 5. 双线章名页眉

格式文件写 `页眉内容：{样式标题:Heading 1}`，页眉就跟着每章的标题走。两件事必须同时成立：

- 稿件里每章都用 `#`（一级标题），写 `##` 就取不到；
- `参考文献` 那个标题在结构上也得是一级标题，否则参考文献那几页的页眉还停在前一章。

## 6. 常见坑

这些都是真实反馈里修出来的，撞上了不报错、只是悄悄不对：

| 现象 | 原因 |
|:--|:--|
| 表格设了居中却靠左 | 分隔行写了冒号才是「每列表态」，整表对齐由 `紧凑：` 那行的对齐决定 |
| 公式把上下两行文字挤住 | 固定行距（`行距20磅`）比公式矮；改用 `行距最小值` 或加大行距 |
| 声明「每页 22 行」却没生效 | 行数有上限：版心高 ÷ 正文行高。超过的声明不会生效，预检会提醒 |
| 目录里没有参考文献 | 参考文献标题没进目录层级 |
| 页码接着前置件往下编 | 见 §3：正文按格式文件的 `起始` 重新起 |
| 附录公式编成 (1-1) | 附录标题没写标识，或没写 `附录公式编号格式` |
| 前置件缺页眉但又要有页码 | `页眉=无` 只关页眉；页码走 `页脚`，别写成 `页脚=无` |
