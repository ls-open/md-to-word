上手

# 安装（Python 3.10+）
pip install md-to-word-docx

# 生成一份格式声明与样例稿件
md-to-word init

# 导出
md-to-word 论文.md --preset zh-academic \
  -o 论文.docx

格式规则写在 format.txt 里，进 Git 管理；稿件正文只写内容，不写排版。

给 AI Agent 用：仓库同时是一个技能目录（SKILL.md），装进 Claude Code 或其他 Agent 后，它会按固定流程读契约、写声明、跑来回复核。
