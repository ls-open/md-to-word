# 标杆样例 2：现代技术白皮书 / 商业研究报告

本样例专为**企业级技术白皮书、行业研究报告、可行性研究报告、商业策划方案与高规格工作公文**设计。

相较于结构复杂的学术学位论文，本样例侧重于**扁平、干练、现代感与高信息密度**，展示了如何用最精简的 Markdown 源码输出规范、美观的商业正式文档。

---

## 一、 核心展示与设计亮点

| 排版要素 | 常见痛点 | 本样例实现方案 |
| :--- | :--- | :--- |
| **开门见山（单节结构）** | 短小精炼的报告不需要复杂分节，但传统排版容易多出一页空白页 | **扁平单节设计**：无目录、无需 `{{< section >}}`，主标题与执行摘要直接在首页呈现，无多余分页，清爽利落。 |
| **现代极简页眉** | 页眉太重或者线条太粗，显得呆板老气 | 采用**单实线 0.5 磅**（最细档是 1/4 磅，0.5 磅是常见页眉线的取值）现代极简商务页眉，页脚配置阿拉伯数字居中页码 `{页码}`，视觉风格轻快稳健。 |
| **APA 国际规范引用** | 商业报告或英文咨询更习惯作者-年份制引用 | 内置 `apa.csl`，正文使用 `[@chacon2014]` 渲染为标准 `(Chacon & Straub, 2014)`，文末参考文献按字母顺序排序，纯悬挂缩进排版。 |
| **全网格线数据表** | 默认表格线条不均，复杂数据表缺乏规整边框 | 采用**全网格线边框（外框 0.75 磅、内线 0.5 磅）**，紧凑版式（五号字、单倍行距），表头加粗居中，数据清晰规整，大幅提升商业数据密度与可读性。 |
| **纯原生现代图表** | 图片导出后带有黑色边框伪影，显得粗糙山寨 | 使用纯原生图片语法，图表绝对居中，无伪影黑边，底部题注清晰，完美融入报告版面。 |
| **工整的数学效能模型** | 商业研报中的量化推导公式排版难看 | 同样支持带编号公式自动右对齐 `(1)`，公式整页居中，展现严谨的专业量化底色。 |

## 二、 目录文件结构

```text
demo/02_modern_report/
├── report_sample.md       # 现代报告 Markdown 源码
├── requirements.txt       # 商业报告样式规则（字体、行距、单线页眉、紧凑表）
├── references.bib         # BibTeX 参考文献数据
├── figures/               # 样例图表（端到端导出耗时实测）
├── report_sample.docx     # 导出的 Word 商业交付物
├── report_sample.pdf      # 对照 PDF 样张
└── page-*.png             # 高清导出页面渲染预览图
```

---

## 三、 一键运行复现

在当前目录下执行以下命令：

```bash
# 1. 导出规范商业 Word 文档（.docx）
bash ../../scripts/export.sh report_sample.md -r requirements.txt -o report_sample.docx

# 2. （可选，仅限 macOS 且装有 Word）顺带输出排版 PDF 对照样张
bash ../../scripts/export.sh report_sample.md -r requirements.txt -o report_sample.docx --pdf
```

## 四、 给 AI Agent 的语法模仿指引

如果您是 AI 助手在处理日常报告、方案或公文，可直接借鉴本样例的设计模式：
1. **不要写 `{{< section >}}`**：普通报告通篇统一阿拉伯页码即可，无需分节符；
2. **章节之间用分页符**：若需要在章与章之间分页，直接独占一行写 `{{< pagebreak >}}`；
3. **参考文献直接选 APA**：YAML 中直接写 `csl: apa.csl`（自动挂载内置样式库），正文用 `[@key]` 即可自动生成作者-年份制括号引用。
