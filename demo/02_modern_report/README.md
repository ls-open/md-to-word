# 样例 2：现代技术白皮书 / 商业研究报告

面向**企业技术白皮书、行业研究报告、可行性研究报告与工作公文**。与学位论文样例相比，这一份
侧重扁平结构与高信息密度：单节、无目录、正文与数据表交替推进。

---

## 一、 本样例演示什么

| 排版要素 | 实现方式 |
| :--- | :--- |
| 单节结构 | 不写 `{{< section >}}`，通篇一套阿拉伯页码，主标题与执行摘要直接落在首页 |
| 极简页眉 | `页眉：… 下边框单线`（线宽用该线型的内置默认值），页脚居中放 `{页码}` |
| APA 引用 | `csl: apa.csl`，正文 `[@chacon2014]` 渲染为 `(Chacon & Straub, 2014)`，文末按字母序排列 |
| 全网格线数据表 | 外框 0.75 磅、内线 0.5 磅，表内五号字单倍行距，表头加粗居中 |
| 图片与题注 | 图片行只写 `![](path){width=…}`，题注另起一段 `%% 图片题注 图 1 …` |
| 带编号公式 | 公式居中、编号 `(1)` 落在版心右端 |
| 样式级颜色 | `一级标题：… 颜色#1F4E79`，颜色按样式声明，不逐处涂色 |
| 多级列表 | 有序、无序、嵌套三级；缩进两格即下一级，落成 Word 原生编号 |
| 引用块 | `> ` 引用块，要求文件用 `引用块：` 一行控制其字体与缩进 |

---

## 二、 目录文件结构

```text
demo/02_modern_report/
├── report_sample.md       # 稿件
├── format.txt             # 格式要求（字体、行距、单线页眉、全网格表）
├── references.bib         # 参考文献数据
├── figures/               # 配图（端到端导出耗时实测）
├── report_sample.docx     # 产物
├── report_sample.pdf      # 核对版 PDF（Word 渲染）
└── page-*.png             # 页面预览图
```

---

## 三、 复现

```bash
bash ../../scripts/export.sh report_sample.md -r format.txt -o report_sample.docx
bash ../../scripts/export.sh report_sample.md -r format.txt -o report_sample.docx --pdf
```

---

## 四、 给 Agent 的照抄要点

1. **普通报告不写 `{{< section >}}`**：通篇统一阿拉伯页码即可，分节只在前置件需要罗马页码时才用；
2. **章与章之间要分页**：独占一行写 `{{< pagebreak >}}`；
3. **参考文献用 APA**：YAML 写 `csl: apa.csl`（自动到内置样式库找），正文 `[@key]` 即可。
