# 标杆样例 1：中文学位论文 / 核心期刊范文

本样例专为**中国高校硕士/博士学位论文、毕业设计、中文核心期刊（知网/万方标准）及严谨学术专著**设计，涵盖了学术排版中最繁琐、手工调格式最痛苦的全部高难度要素。

无论是由人类直接参考，还是让 AI Agent 学习标准排版语法，本样例都可作为全要素的标准范本。

---

## 一、 核心展示与设计亮点

| 排版要素 | 常见痛点 | 本样例实现方案 |
| :--- | :--- | :--- |
| **分节与独立页码** | 封面/目录/正文页码混在一起，很难分别设置 | **双节体系**：前置件（摘要、目录）采用**小写罗马数字（`i, ii...`）**；正文从第一章起自动重置为**阿拉伯数字（`1, 2...`）**从 1 连续编号。 |
| **Word 动态目录** | Markdown 无法生成带点线制表位和真实页码的目录 | 使用 `{{< toc 2 >}}` 短代码插入 Word 原生动态目录域，**收录到二级标题**（本样例的一级章名与 `1.1`、`2.1` 这类小节都在目录里），正文页码变动后按 `F9` 刷新。 |
| **动态章名页眉** | 页眉文字固定死，无法随第一章、第二章自动切换 | 采用**下边框双线**页眉，嵌入 `{样式标题:Heading 1}` 动态域，每一页页眉自动抓取当前章标题；前置节（目录/摘要）自动隐去页眉。 |
| **数学公式居中与按章编号** | 传统导出公式编号乱跑，只能手工敲空格对齐 | 原生 OMML 公式 + 段落制表位：**公式本体居中，编号按章编（学位论文写法 `（2-1）`）并落在版心右端**；正文引用写 `@eq-x`，落成「式（2-1）」。 |
| **学术标准三线表（表 1 真的跨页）** | 表格线条全黑边，跨页后第二页没有表头 | 声明式三线表（顶底线 1.5 磅、栏目线 0.75 磅）；表 1 有 30 行、确实排到两页，**第二页顶部自动重现表头行**——这条能力在本样例里是看得见的，不只是声称。 |
| **国标参考文献** | 序号格式难调，文末文献排版容易混乱 | 内置 `chinese-gb7714-2015-numeric.csl`，正文使用 `[@key]` 自动生成 `[1]` 顺序编码，文末自动对齐悬挂缩进。 |
| **版式细节（装订线 / 文档网格 / 字符间距）** | 学位论文规范里常按「每页多少行」规定版式，装订线还要额外留 | `requirements.txt` 三行搞定：`装订线：1cm`、`文档网格：每页22行`、标题行加 `字距1磅`。网格会按正文行距倍数自动补偿，**声明的 22 行就真的是 22 行**，不用再去调行距。 |
| **纯原生图片排版** | 图片意外继承表格边框（上下带黑线） | 图片行只写 `![](path){width=13cm}`，题注另起一段 `%% 图片题注 图 1 …`；图片段落没有任何表格包装，不会带出黑边。 |

## 二、 目录文件结构

```text
demo/01_chinese_thesis/
├── thesis_sample.md       # 标准全要素 Markdown 稿件（可直接看源码语法）
├── requirements.txt       # 声明式中文格式规范（字体、字号、边框、页码等）
├── references.bib         # BibTeX 参考文献库
├── figures/               # 样例图表（系统架构图、质量门禁流程图）
├── thesis_sample.docx     # 一键导出的 Word 交付物（可直接用 Word 打开看效果）
├── thesis_sample.pdf      # 通过 Microsoft Word 打印导出的对照 PDF
└── page-*.png             # 高清导出页面渲染预览图
```

## 三、 一键运行复现

在当前目录下执行以下命令，即可在数秒内完成编译、门禁核验与 Word 导出：

```bash
# 1. 导出规范 Word 文档（.docx）
bash ../../scripts/export.sh thesis_sample.md -r requirements.txt -o thesis_sample.docx

# 2. （可选，仅限 macOS 且装有 Word）顺带输出排版 PDF 对照样张
bash ../../scripts/export.sh thesis_sample.md -r requirements.txt -o thesis_sample.docx --pdf
```

## 四、 给 AI Agent 的语法模仿指引

如果您是 AI 编码/写作助手，在为用户生成类似的学位论文或学术稿件时，请参照本样例中的以下黄金契约：
1. **分节符位置与语义**：`{{< section 页码=小写罗马 起始=1 >}}` 必须独占一行且前后留空行，紧跟在目录后、第一章 `#` 之前；**它描述的是它上面那一节（前置件），不是后面的正文**——正文页码由 `requirements.txt` 的 `页码：` 决定；**它后面不要再写 `{{< pagebreak >}}`**（会多顶出一页，导前预检会拦）；
2. **公式写法**：带编号公式统一用 `$$...$$ {#eq-xxx}`，正文中用 `@eq-xxx` 引用；要按章编号就在 YAML 的 `crossref:` 下加 `chapters: true`；中文稿默认就是学位论文的写法 `（2-1）`（全角括号 + 短横），英文稿默认 `(2.1)`，要别的外观就在 `requirements.txt` 写一行 `公式编号格式：（{c}-{n}）`；
3. **表格题注**：上方表题写 `%% 表题 表 1 …`，下方表注写 `%% 表注 注：…`；
4. **图片语法**：图片行只放无障碍替代文字 `![](path){width=13cm}`，题注**另起一段**写成 `%% 图片题注 图 1 …`（写在图上方还是下方由作者定）；不要给图片加 `{#fig-xxx}` 标签，也不要把题注写进方括号——后者会被预检拦下。
